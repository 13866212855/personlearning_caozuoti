## 操作题模拟器「撤销/重做 + 恢复」方案设计（仅设计，未改代码）

- 需求：Word 误删段落可恢复；Excel 等操作题支持 Ctrl+Z 恢复。
- 现状结论（读代码得出）：
  - 四个模拟器均为受控组件，所有修改都经 `onChange(next)` 上报，可在 `SimulatorRenderer` 统一拦截。
  - 无任何撤销机制；Word 删除段落/表格/图片、Excel 删图表、文件管理删除均即时生效、无确认。
  - 判分引擎 `word_paragraph_style` / `word_text_contains` 使用 `paragraphIndex`（按段落下标），误删一段会导致后续下标全部错位。
  - 考试页每 10s 服务端草稿，刷新可恢复；错题重做页 `/mistakes/[id]` 无草稿，且「重置操作」无确认。
  - 考试页 `<SimulatorRenderer>` 未设 `key`，同类型题目切换时保留上一题的组件内部状态。
- 推荐方案：快照式历史栈（不用命令模式），落在 `hooks/useUndoHistory.ts` + `lib/simDiff.ts`，由 `SimulatorRenderer` 接入；按题缓存历史；输入按「同目标 + 仅文本/值变化 + 800ms 内」合并为一步；删除类操作用 toast「已删除… [撤销]」而非弹窗。
- 待用户确认：删除是否二次确认、考试中是否提供「恢复本题初始状态」、错题重做页是否加本地草稿。
